# Cyberbullying Detection in Social Media Text Using Transformer-Based NLP

## About the Project

This project focuses on detecting cyberbullying and toxic content in social media text using Natural Language Processing (NLP) and Machine Learning.

The project compares traditional machine learning models with transformer-based models to identify harmful or toxic language in online conversations.

## Models Used

- BERT
- DistilBERT
- Random Forest
- XGBoost

## Dataset

The project uses the Jigsaw Toxic Comment Classification dataset.

The dataset contains Wikipedia talk page comments labeled for different types of toxic behavior, including:

- Toxic
- Severe Toxic
- Obscene
- Threat
- Insult
- Identity Hate

## Project Goals

- Detect toxic and cyberbullying-related language.
- Compare traditional machine learning and transformer-based approaches.
- Analyze linguistic patterns associated with toxic content.
- Evaluate model performance using appropriate classification metrics.

## Technologies

- Python
- Hugging Face Transformers
- PyTorch
- Scikit-learn
- Pandas
- NumPy
- Google Colab

## Results

Among the evaluated models, the transformer-based models showed strong performance for toxic-content detection. DistilBERT achieved an AUC of 0.9898 and an accuracy of 92.74% in our experiments.
